
# 网络模型

### 物理层
0和1原始比特流
### 数据链路层
局域网物理寻址
### 网络层
跨网段寻址，路由转发
### 传输层
tcp udp
### 会话层
web开发中的cookie/session机制
### 表示层
tls/ssl：提供数据加密
数据格式：json、xml、jpeg等媒体格式
加密算法：对载荷处理的算法，aes，rsa等
### 应用层 
http
dns
ftp
smtp/pop3/imap 电子邮件收发协议
websocket： 基于tcp的全双工通信协议
# http特性

http协议为以下几大类：opitons、get、post、put、delete。
传参模式
1. 字符传参
    test?name=11&age=12
2. json方式
   服务端要求你传递json格式，那么你传递的数据，就必须按照他的要求来
```
{

"code": "",

"password": "",

 "phone": "",

 "username":"test"

 }
```
